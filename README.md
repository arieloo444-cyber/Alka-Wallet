# Alke Wallet - Frontend Dinámico

Desarrollo del front-end dinámico para una billetera digital que permite a los usuarios gestionar sus activos financieros de manera segura y sencilla.

## Tecnologías Utilizadas

* **HTML5:** Estructura semántica de la aplicación.
* **CSS3:** Estilos personalizados.
* **JavaScript:** Lógica de interactividad y manipulación de datos en el cliente.
* **Bootstrap:** Framework para agilizar el diseño responsivo de la interfaz de usuario.
* **jQuery:** Librería para optimizar la manipulación del DOM y la gestión de eventos.

## Estructura del Proyecto

El flujo de trabajo se gestiona mediante control de versiones y está estructurado de la siguiente manera:

* `index.html`: Página principal de acceso.
* `pages/`: Contiene las vistas dinámicas de la aplicación (`login.html`, `menu.html`, `deposit.html`, `sendmoney.html`, `transactions.html`).
* `css/`: Hojas de estilo (`styles.css`).
* `js/`: Lógica de la aplicación (`app.js`).
* `img/`: Recursos gráficos (`hero.png`, `logo.png`).

## Funcionalidades

* Registro e inicio de sesión de usuarios.
* Panel de administración de fondos y saldo.
* Simulación de transferencias y envíos de dinero.
